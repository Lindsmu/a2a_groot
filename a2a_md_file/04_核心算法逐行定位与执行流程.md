# GR00T 潜空间 A2A：核心算法逐行定位与执行流程

## 1. 先澄清“历史动作为什么能去噪”

A2A 不是把历史动作当成噪声，也不是要求历史动作本身带有高斯噪声。

原始 GR00T 学习：

```text
随机噪声 x0 -> 未来动作 x1
```

A2A 学习：

```text
历史轨迹 latent z0 -> 未来轨迹 latent z1
```

Flow Matching 只要求定义 source distribution、target distribution 和中间概率路径；source 不必是 Gaussian。历史动作包含机器人当前运动趋势、接触反馈和任务阶段，因此通常比随机噪声离未来动作更近。模型学习的是条件 transport/velocity field，不是传统意义上“把历史噪声擦干净”。

代码中的 0.02 history noise 是训练正则和多模态消融支持，不是把历史定义为噪声。默认推理噪声为 0，因此默认输出是确定性的。

## 3. Action Head 初始化的逐段解释

文件：`gr00t/model/gr00t_n1d7_a2a/gr00t_n1d7_a2a.py`。

### 行 91-129：基础字段和训练阶段门禁

- `91-99`：保存 action dim、horizon、latent dim、backend、Euler steps 和 stage。
- `100-107`：AE/joint 必须让 trajectory encoder/decoder 可训练。
- `108-112`：AE-only 不使用 VLM，所以拒绝“声明 tune_llm/tune_visual 但计算图绕过”。
- `113-114`：flow/joint 必须允许 velocity field 训练。
- `115-127`：Euler steps、noise、loss weights 合法性。
- `128-129`：即使 config 构造后被外部修改，也再次验证。

### 行 132-146：条件分支

- `vlln` 保留 GR00T VLM LayerNorm 兼容；
- `VLMConditionPooler` 将 backbone `[B,S,C]` 汇聚到 `[B,512]`；
- current state condition 默认关闭，只能作为非 strict 消融。

### 行 147-172：MLP 分支

```text
trajectory_encoder = ActionTrajectoryEncoder
trajectory_decoder = ActionTrajectoryDecoder
flow_net = LatentFlowNet
latent_summary_projection = Identity
```

这条路径的 latent 始终是 `[B,512]`。

### 行 173-208：DiT 分支

```text
trajectory_encoder = ActionTrajectoryTokenEncoder
trajectory_decoder = ActionTrajectoryTokenDecoder
flow_net = LatentDiTFlowNet
latent_summary_projection = LayerNorm + Linear(C -> 512)
```

Flow latent 是 `[B,8,C]`。`latent_summary_projection` 只为 mixed-action auxiliary head 保持原 512 维接口；它不把 DiT 主速度场重新池化成单向量。

### 行 209-217：auxiliary head 和冻结

辅助 head 输入是 `[VLM condition, future latent summary]`，输出完整 `[8,D]` logits；mask 决定每个位置用 continuous decoder、tanh regression、sigmoid binary 还是 grouped categorical。

## 4. MLP trajectory encoder

文件：`gr00t/model/modules/a2a_latent.py:147-220`。

输入：

```text
trajectory      [B,H,D]
trajectory_mask [B,H,D]
embodiment_ids  [B]
```

执行：

1. CategorySpecificLinear 按 embodiment 将 D 维动作映射到第一层通道；
2. 转成 Conv1d 需要的 `[B,C,H]`；
3. 3 层 kernel-5 Conv1d 提取时间局部模式；
4. mask 折叠成 token validity；
5. masked temporal pooling 得到固定向量；
6. projection/normalization 得到 `[B,512]`。

同一个实例先后编码 history 和 future，因此两段轨迹位于同一个 latent 坐标系。

## 5. DiT token encoder

文件：`gr00t/model/modules/a2a_latent.py:222-305`。

与 MLP encoder 的关键差异：

```text
MLP：最后沿 H 做 masked pooling -> [B,512]
DiT：保留 H 个时间位置         -> [B,H,C]
```

行 `269-305` 的 forward 在输入适配前将 invalid 值清零，并在每一层 temporal convolution 后再次用 token mask 清零。这样，repeat-first 的占位数值不会通过卷积感受野泄漏到真实 token。

它不是：

```text
[B,512] -> reshape -> [B,8,64]
```

而是 Conv 输出本来就保留时间轴，因此第 i 个 token 对应第 i 个相对轨迹位置。

## 6. VLM condition

文件：`gr00t/model/modules/a2a_latent.py:453-502`。

输入：

```text
hidden_states  [B,S,C_backbone]
attention_mask [B,S]
image_mask     [B,S]
text_mask      [B,S]
```

它分别做 masked global/image/text pooling，再投影成 A2A condition。与论文 ResNet18 条件网络不同，这里保留 GR00T 的视觉语言理解能力。

DiT 没有对 VLM token 做 cross-attention；VLM condition 通过 AdaLN 注入 action token blocks。

## 7. 训练 forward：从输入验证到总损失

文件：`gr00t/model/gr00t_n1d7_a2a/gr00t_n1d7_a2a.py:445-580`。

### 行 445-454：取输入并验证

```text
history         = history_action_canonical
future          = future_action_canonical
history_mask    = history_action_mask
continuous_mask = continuous_action_mask
```

先调用 `_validate_action_input` 和 `_validate_continuous_channel_support`。这一步在任何公式前拒绝错误 shape、NaN/Inf、无 continuous sample、mask overlap 和 support mismatch。

### 行 456-458：训练 history noise

```python
history = history + std * randn_like(history) * history_mask
```

只对有效 history channel 加噪；padding 不加噪。默认 train std=0.02，infer std=0。

### 行 460-464：future autoencoder

```text
z1 = E_a(future)
future_reconstruction = D_a(z1)
L_AE = masked_L1(reconstruction, future)
```

### 行 465-487：AE-only 快速返回

AE warmup 不运行 VLM 和 FlowNet。它仍计算 z0/z1 诊断，但总 loss 只有 AE。

### 行 489-505：Flow Matching

```python
condition = self._condition(...)
z0 = self.trajectory_encoder(history, ...)
tau = torch.rand(B, dtype=float32)
path_tau = tau.reshape([B,1] or [B,1,1])
z_tau = (1-path_tau) * z0 + path_tau * z1
target_velocity = z1 - z0
predicted_velocity = flow(z_tau, tau, condition)
loss_fm = mse(predicted_velocity, target_velocity)
```

为什么 target 是 `z1-z0`：线性路径 `z(t)=(1-t)z0+t z1` 对 t 求导就是常向量 `dz/dt=z1-z0`。

### 行 507-528：Integration Consistency

内部 `velocity_field` 捕获真实 history validity。`euler_integrate` 从 z0 运行可微积分，再同时比较 latent 和 decoded action：

```text
z1_inferred = Euler(z0)
L_IC_latent = L1(z1_inferred,z1)
L_IC_action = masked_L1(D(z1_inferred),future)
L_IC = L_IC_latent + 0.5*L_IC_action
```

### 行 530-543：mixed action auxiliary loss

- regression：tanh 后 masked L1；
- binary：masked BCEWithLogits；
- categorical：按 group index 计算 CE；
- 无对应通道时 loss 安全为 0。

### 行 544-559：stage-dependent 总损失

```text
joint     = FM + 0.5 AE + IC + aux
flow_only = FM + IC + aux
autoencoder = AE
```

### 行 561-580：输出诊断

返回 component losses、action prediction、z0/z1/z1_inferred、latent std 和 pair distance，供 Trainer 记录。

## 8. MLP velocity field

文件：`gr00t/model/modules/a2a_latent.py:504-581`。

每个 AdaLN residual MLP block：

```text
h = LayerNorm(z)
(shift, scale, gate) = condition_network([VLM condition, time embedding])
h = h * (1+scale) + shift
z = z + gate * MLP(h)
```

4 个 block 之后输出与 latent 同维的 velocity `[B,512]`。

## 9. DiT velocity field

### 9.1 显式 self-attention

文件：`gr00t/model/modules/a2a_latent.py:588-631`。

```text
Q,K,V = Linear(x).chunk(3)
Q/K/V -> [B,heads,H,head_dim]
score = Q K^T / sqrt(head_dim)
prob = softmax(score)
context = prob V
output = Linear(context)
```

该实现与标准多头自注意力数学等价，但导出为普通 ONNX MatMul/Softmax 算子。

### 9.2 AdaLN-DiT block

文件：`:633-689`。

一个 block 有两条残差：

```text
x = x + gate_attn * Attention(AdaLN_attn(x))
x = x + gate_mlp  * FFN(AdaLN_mlp(x))
```

condition network 为两条分支分别产生 shift、scale、gate。

### 9.3 完整 DiT FlowNet

文件：`:691-800`。

- `701-749`：构造 time embedding、condition projection、位置 embedding、validity embedding、N 个 block、final LayerNorm/Linear。
- `750-800`：验证 `[B,H,C]`，把 flow time 与 VLM condition 融合，再依次运行 blocks。

validity embedding 告诉模型哪些 history token 是真实，哪些是 cold-start padding。padding token 不被删除，因为未来同一位置仍必须输出。

## 10. decoder 和 mask merge

### MLP decoder

文件：`gr00t/model/modules/a2a_latent.py:325-377`。

输入 `[B,512]`，通过 4 个 residual MLP，再用 CategorySpecificLinear 产生 `[B,8,D]`。

### DiT decoder

文件：`:379-451`。

输入 `[B,8,C]`，在 decoder 边界展平为一个完整 chunk 表示，再通过 4 residual blocks 输出 `[B,8,D]`。展平发生在 velocity field 完成之后，不影响 DiT 的时间 attention。

### 合并

文件：action head `:426-444`。

continuous decoder、regression、binary、categorical 按互斥 mask 写入最终 action。无效/padding 位保持 0。

## 11. 推理逐行解释

文件：action head `:583-623`。

- `589-596`：切换 frozen eval，验证仅 history 输入和 masks。
- `597-599`：可选推理 history noise；默认 0。
- `600`：编码真实历史得到 z0。
- `601`：生成 token validity，MLP 可忽略，DiT 使用。
- `602-604`：取默认或 per-request Euler steps。
- `606-612`：定义带 VLM condition/validity 的 velocity field。
- `614`：从 z0 积分到未来 latent。
- `615`：decoder + auxiliary merge 得到未来动作。
- `616-622`：返回动作、z0、最终 latent 和 step 数。

完整伪代码：

```python
history = processor(observation_history)
z = encoder(history)
c = pool(VLM(image, text))
for i in range(num_steps):
    t = i / num_steps
    z = z + (1 / num_steps) * flow(z, t, c)
future = decoder(z)
return denormalize_and_merge(future)
```

## 12. 刚启动时的真实执行流程

### Policy 部分

文件：`gr00t/policy/gr00t_policy.py:463-536`。

1. 检查调用者给的是单帧还是完整 8 帧；
2. 单帧：追加到 `A2AProprioHistoryBuffer`；
3. 完整 8 帧：验证 key/shape/timestamp 后替换外部 history；
4. 只有 buffer 接受时间戳后才提交 synthetic clock；
5. `require_full_history` 且 mask 未全 1 时拒绝；
6. 把 `[8]` valid mask 写入 metadata 给 processor。

### Buffer 部分

文件：`gr00t/policy/a2a_history.py:518-587`。

ring buffer 按真实时间顺序恢复数据。`repeat_first_state` 只复制数值用于固定 tensor shape，但 valid mask 保留真假；因此模型不会把复制值误认成 8 个真实反馈。

## 13. processor 如何生成模型输入

文件：`gr00t/model/gr00t_n1d7_a2a/processing_gr00t_n1d7_a2a.py:563-666`。

输出关键字段：

```text
history_action_canonical [B,8,D]
future_action_canonical  [B,8,D]      # 训练才有
history_action_mask      [B,8,D]
continuous_action_mask   [B,8,D]
auxiliary/binary/categorical masks
embodiment_id
```

history/future 调用同一个 `_normalize`，使用同一套 canonical statistics。模型输出后 `decode_action:678-700` 按相同边界反归一化。

## 14. 为什么 DiT 不一定更好

DiT 能表示更复杂的跨时间依赖，但代价是：

- 参数量、显存和延迟更大；
- 小数据更容易过拟合；
- `[8,256]` 有 2048 latent 元素，不是与 512 向量等预算；
- 如果 canonical 数据语义错误，更大模型只会更强地拟合错误；
- 论文核心已经用 4-block MLP 获得好结果，DiT 没有论文实验证据保证更优。

因此必须同时比较 DiT-64 和 DiT-256，并以闭环成功率而非训练 loss 决策。
