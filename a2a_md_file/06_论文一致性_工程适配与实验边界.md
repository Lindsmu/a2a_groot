# 潜空间 A2A：论文一致性、GR00T 工程适配与实验边界

## 1. 三层概念必须分开

### 论文核心方法

```text
历史动作 -> 共享 encoder -> z0
未来动作 -> 同一 encoder -> z1
latent Flow Matching: z0 -> z1
decoder -> 未来动作
```

### GR00T-A2A 默认 MLP

保留上述公式和 512 latent/3 Conv/4 AdaLN-MLP/4 decoder block，把论文视觉条件网络换成 GR00T VLM，并增加数据/部署工程能力。

### GR00T-A2A DiT

保留上述公式，但把 `[B,512]` latent 和 4-block MLP velocity field 改成 `[B,8,C]` token latent 和 temporal DiT velocity field。它是对照实验扩展，不是论文报告的原 action head。

## 3. GR00T 迁移带来的有意差异

### 3.1 条件主干

论文使用 ResNet18/视觉条件；本项目使用 GR00T 的 VLM、语言 token 和 `VLMConditionPooler`。这是“迁移到 GR00T”的必要变化，不是论文逐比特复刻。

### 3.2 视觉历史长度

论文实验配置使用 8 帧视觉历史。项目 A2A pipeline 只强制 state/action 为 8/8，不强制 video delta；示例保留 `video=[0]`。因此当前默认是“论文 A2A action method + GR00T 原视觉配置”，不能称为完整论文实验架构。

若要做更严格对照，应新增/设置 video `[-7..0]`，并验证 VLM 显存、frame ordering 和 processor 结果。

### 3.3 多 embodiment

CategorySpecificLinear/MLP 是 GR00T 多机器人支持，不是论文单一 action space 的原样实现。

### 3.4 mixed action

论文核心主要讨论 continuous action，并把 binary gripper/hybrid support 作为局限。本项目增加 regression/binary/categorical auxiliary head。纯 continuous 数据下 `L_aux=0`，才是论文 Eq.6 的原样路径。

### 3.5 数据安全和部署

shared canonical statistics、controller contract SHA、strict episode window、cold-start、checkpoint migration、ONNX/TensorRT 都是工程补强，不是论文 action 网络的一部分。

## 4. 论文未公开、项目必须自行固定的实现选择

论文没有公开所有内部宽度和算子细节。项目固定：

```text
encoder channels = (128,256,512)
MLP expansion ratio = 4
activation = SiLU/GELU（按模块）
normalization = LayerNorm
time embedding = FP32 sinusoidal
IC train Euler steps = 1
```

这些是明确、可测试、可复现的仓库选择，但不能声称来自未公开作者源码。

## 5. DiT 与论文的关系

论文核心 A2A velocity field 是 4-block AdaLN-MLP。当前 DiT 后端是用户要求的方案一：把 latent 变成时间序列 token，再使用 self-attention。

它仍然满足：

```text
z0 = E(history)
z1 = E(future)
z_tau = (1-tau)z0 + tau z1
target = z1-z0
inference starts from z0
```

所以它是 A2A Flow Matching，但不是论文原 action head。任何实验报告都应写成：

```text
GR00T-A2A-MLP（paper-core migration）
GR00T-A2A-DiT（temporal-token ablation/extension）
```

## 6. noise 的准确解释

项目默认：

```text
train history noise std = 0.02
inference history noise std = 0.0
```

0.02 是论文启发的扰动/多模态消融值，不应描述成所有论文主结果唯一固定超参。论文不同不确定性实验还使用其他噪声水平。

若要观察同一 history 下的多模态 rollout，需要推理也显式设置非零 noise，并用多个随机 rollout 统计；默认 0 是确定性低方差部署配置。

## 7. 时间对齐的关键前提

论文符号是：

```text
history = a[t-7 ... t]
future  = a[t+1 ... t+8]
```

仓库 loader 是：

```text
state delta  = [-7 ... 0]
action delta = [0 ... 7]
```

两者仅在数据的 action row 0 定义为“观察当前帧后将执行的下一动作”时等价。如果 row 0 表示同步 `a_t`，canonicalizer 必须做时间平移。contract 中的字符串声明不能替代对数据生成器事实的核查。

## 8. 为什么 raw LIBERO 不符合当前 continuous A2A

raw LIBERO：

```text
state  = absolute measured EEF xyz + absolute rotation-vector + 2D gripper qpos
action = OSC_POSE delta command + 1D gripper command
```

它们的单位、目标定义和控制器语义不同。后续 delta action 又相对每一步新的 measured state，不能只用当前 q[t] 精确恢复整个 absolute goal chunk。旋转必须用 SO(3) 矩阵复合，不能逐分量相加。

当前 strict processor 拒绝 raw LIBERO 是安全门禁。完整支持需要：

1. 离线读取每一步 measured state；
2. 使用锁定版本的 OSC controller scale/frame/rotation rule；
3. 生成 grouped canonical pose/goal 列；
4. gripper 单独 binary；
5. 在线每控制子步用 fresh measured state 做 inverse-controller，或 `n_action_steps=1` 重规划；
6. contract 绑定 controller 版本和所有转换细节。

## 9. 尚未实现的论文消融

当前生产实现没有完整复现论文所有实验矩阵，例如：

- 原始动作空间 raw-A2A MLP/UNet；
- regression-latent 对照；
- 所有视觉历史/噪声/solver steps 消融；
- 论文原任务、3 seed 和全部成功率表格。

这些不是默认潜空间 A2A 方法运行所必需，但不能称为“完整复现论文所有实验”。

## 10. 效果结论应如何表述

可以写：

> 已在 GR00T N1.7 上实现潜空间 A2A 的共享轨迹自编码器、latent Flow Matching、AE/IC loss 和 history-start inference，并增加 MLP/temporal-DiT 双后端、严格 canonical 数据契约与部署路径。软件专项测试和原模型回归通过。

目前不能写：

> 已经复现论文成功率，或 DiT 一定优于 MLP。

要得到效果结论，至少需要相同 canonical 数据、相同训练预算、3 个 seed、闭环成功率、1/2/4/6 steps 延迟/成功率和原始 GR00T 对照。
