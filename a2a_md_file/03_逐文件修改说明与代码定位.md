# GR00T 潜空间 A2A：逐文件修改说明与代码定位

## 1. 如何使用本文件

本实现相对 NVIDIA `GR00T N1.7 General Release` 提交 `1a1837f...` 共涉及 52 个文件：34 个新增，18 个修改。

下面的行号对应当前桌面最终源码。需要查看每一行原文时，打开同目录下：

```text
逐行源码定位/<相对路径>.txt
```

每一行格式是：

```text
00001 | 原始源码
```

因此即使在普通文本编辑器中，也能与本文行号、统一 patch 和项目源码相互定位。

## 2. 总体调用关系

```text
Finetune CLI
  -> Config.load_dict 恢复 Gr00tN1d7A2AConfig
  -> Gr00tN1d7A2APipeline
  -> A2AShardedSingleStepDataset
  -> Gr00tN1d7A2AProcessor
  -> GR00T VLM backbone
  -> Gr00tN1d7A2AActionHead
       -> shared trajectory encoder
       -> MLP FlowNet 或 temporal DiT FlowNet
       -> Euler integration
       -> trajectory decoder + auxiliary head
  -> action decode

Online policy
  -> A2AProprioHistoryBuffer
  -> processor/history mask
  -> model.get_action

Deployment
  -> A2A ONNX exporter
  -> artifact identity metadata
  -> A2A TensorRT builder/runtime
```

## 4. 数据 schema、严格窗口和 canonical contract

## 6. A2A 核心网络模块

### `gr00t/model/modules/a2a_latent.py`（新增，1-853）

公共 helper：

- `36-68`：trajectory/token mask 规范化。
- `70-76`：masked token mean。
- `78-110`：masked L1，包含全空 mask 安全行为。
- `112-145`：FP32 sinusoidal flow-time embedding。

MLP 后端：

- `147-220`：`ActionTrajectoryEncoder`，3 Conv + masked pooling -> `[B,512]`。
- `307-323`：residual MLP block。
- `325-377`：`ActionTrajectoryDecoder`，latent -> 未来 action chunk。
- `504-532`：AdaLN residual MLP block。
- `534-581`：`LatentFlowNet`，默认 4 block velocity field。

DiT 后端：

- `222-305`：token encoder，保留 `[B,H,C]` 时间轴并隔离 padding。
- `379-451`：token decoder，在 decoder 边界展平 token，保留整段相关性。
- `583-586`：token AdaLN 调制 helper。
- `588-631`：显式 ONNX-friendly QKV temporal self-attention。
- `633-689`：AdaLN-DiT block，attention/FFN 双残差和 gate。
- `691-800`：`LatentDiTFlowNet`，位置/validity embedding、N 个 block、final projection。

共享模块：

- `453-502`：VLM condition pooler，组合 masked global/image/text summary。
- `802-853`：任意 latent rank 的可微 Euler integration。
